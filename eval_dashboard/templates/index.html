Methodology & Reproduction

Client Loop & Architecture

Evaluations run via an agent loop built on the official MCP Python SDK with modern streamable HTTP transport (Mcp-Method headers and SSE stream decoding). The assistant-under-test connects directly to the deployed MCP server on Azure VM with zero mock bypasses.

Proxy Notice: The evaluation runner uses the official MCP Python SDK loop (not the Claude Code CLI) with free-tier open models (assistant: openai/gpt-oss-20b / qwen/qwen3.8-27b, simulator: openai/gpt-oss-120b). Benchmark results serve as a proxy for the graders' Claude Code + Claude 3.5 Haiku evaluation environment.

  • Authentication: Real OAuth 2.1 authorization code flow with PKCE S256, explicit resource parameters, and OTP retrieval from SMS gateway.
  • Provider & Model Split: Assistant-under-test and simulator run on separate model endpoints to prevent shared rate-limit depletion.
  • Database & Web Parity: Post-conversation verification connects directly to PostgreSQL (port 5432) to verify applications, assistant_submissions, and audit_log tables, checks citizen portal at /status, and computes non-interference snapshots.
  • Cleanup Guarantee: Guaranteed cleanup in a finally block deletes marker mobile records after every persona execution.

What Is NOT Covered (Out of Scope)

  • Biometric Hardware Authentication: Physical fingerprint/iris scanners at CSC kiosks cannot be stimulated via MCP JSON-RPC; mocked as successful physical verification in citizen persona pre-conditions.
  • Physical Paper Seals & Holograms: Physical scrutiny of embossed seals on legacy land or age certificates is performed out-of-band by field verification staff before submission.
  • Telephony & IVR Audio: Interactive voice phone channels are translated to text transcripts; audio codec latency is not part of the MCP eval harness.

Known Flaky Cases

  • Free-Tier Rate Limits (TPD / TPM): Free API tiers enforce strict daily token quotas (e.g. 200k TPD on Groq). Sudden 429 backoffs can cause a persona turn to terminate prematurely; recorded as model weakness rather than application defects.
  • Malformed Function Call Emulation: Smaller open-source models occasionally emit unescaped JSON inside argument objects or fail to terminate multi-turn dialogues cleanly without [END] markers.
  • Assamese Unicode Font Rendering: Complex conjunct glyphs in Assamese script (e.g. ক্ষ, ণ্ড, ঞ্জ) require modern UTF-8 terminal rendering; older shells may render decomposed character sequences.
